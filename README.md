# DealScope

DealScope は、ホールカードとボードを入力すると、現在のカード勝率を表示する小型Webツール。
SPECTRAとは独立しており、レンジ・GTO・戦略解説などは扱いません。詳しい仕様は [SPEC.md](SPEC.md) を参照。

## 使い方

1. 画面下の ▼ を押してカードピッカーを開く(閉じるときは ×)
2. カードを選ぶと、次の未入力枠へ自動で移動する
3. 勝率が各プレイヤー行の右側に表示される(左には、いま作れている役。Flop以降)。ボードは Flop(3枚) → Turn → River の順に、横一列で入力する

- 入力済みの枠をタップすると選び直せる(「外す」で空にもできる)。入力中の枠は、カードの上の ▼(上下に動く)で示す
- ピッカー上部の ‹ › で、カードを選ばずに前の枠・次の枠へ移れる
- 他の枠で使用中のカードはピッカーで選べない
- 画面右上の `?` でヘルプを開く
- 画面上部の「ランダム配布」は、**空欄だけ**をランダムなカードで埋める(入力済みのカードは変わらない。範囲は今のストリートまで)。「全消去」は全カードを消す(モード・人数は維持)。全部作り直したいときは「全消去 → ランダム配布」
- 入力中のカードは端末に保存され、リロードしても復元される

## モード

| モード | 人数 | 入力 | 計算 |
|---|---|---|---|
| 既知ハンド | 2〜4人 | 全員のカード2枚 | Exact(完全列挙) |
| ランダム相手 | 相手1〜4人(最大5人卓) | Hero のカード2枚だけ | 相手1人でFlop以降: Exact / それ以外: Monte Carlo(`≈` 付き) |

- 人数を減らしたときだけ、いなくなったプレイヤーのカードは破棄される。モードを切り替えても入力は残り、既知ハンド → ランダム相手 → 既知ハンドと戻ると P1〜P4 が復活する(ランダム相手の Hero は既知ハンドの P1 と同じ枠)
- 復活するとき、Board・Hero と同じカードが重なっていたら、隠れていた P2〜P4 側を空欄にする
- ランダム相手は、相手のカードがランダムだと仮定した勝率。Monte Carlo(100,000回)の数字は実行のたびに少し変わる
- 計算するのは、ボード0枚(Preflop) / Flop3枚 / +Turn / +River のとき。Flopが1〜2枚の入力途中などは「入力待ち」

## 近似値(≈)とモンテカルロ法

ランダム相手の `≈` が付いた数字は、カードをランダムに100,000回配って勝敗を数えた近似値(モンテカルロ法)。実行のたびに数字が少し変わり、ずれは最大で±0.3ポイント程度(1σは0.16ポイント以下)。試行回数を4倍にしても、誤差は半分にしかならない。手順・誤差の見積もり・速度・検証は [SPEC.md](SPEC.md) の「12. 付録: Monte Carlo シミュレーションの詳細」を参照。

## 最終役の見込み

勝率の下の「最終役の見込み ▼」を開くと、**各プレイヤーが最終的にどの役になるか**の割合を表で見られる。

- 意味は「起こりうる全パターンのうち、そのプレイヤーの最終役がその役になる割合」。**その役で勝つ確率ではない**(「何で勝ったか」は別の統計で、未対応)
- 勝率と同じ計算の副産物として数えるので、追加の計算時間はほぼない。既知ハンドは Exact の割合、ランダム相手の近似(`≈`)は Monte Carlo の集計
- ランダム相手モードの列は「Hero」と「相手(1人あたり)」

## 光るカード

Flop以降、全員のカードがそろうと、**全員の中でいちばん強いハンドの5枚**が金色の線で囲まれる(それ以外のカードは暗くなる。ボード3枚+手札2枚 / ボード4枚+手札1枚 / ボード5枚、など)。各プレイヤーの最強を全員分光らせるわけではない。同じ強さのプレイヤーがいるときは、その全員のカードが光る。

## 勝率の定義

引き分けは取り分を等分して計算する(ポット分配を考慮したequity相当)。

## URL

入力状態はURLの `#` 以降に反映される(開くだけで同じ局面を再現できる)。

```
#AdTs-2c7h                      既知ハンド2人。P1 = A♦T♠、P2 = 2♣7♥
#AdTs-2c7h/Kh7d3s/Qc/2h         + Flop K♥7♦3♠ + Turn Q♣ + River 2♥
#AdTs-2c7h-KdKs                 既知ハンド3人
#AdTs-??-??/Kh7d3s              ランダム相手(相手2人) + Flop
```

- `P1[-P2[-P3[-P4]]]/Flop/Turn/River`。ランダム相手は `Hero-??[-??…]`(`??` が相手1人)
- カードは「ランク(`AKQJT98765432`)+スート(`shdc`)」の2文字。読み込み時は大文字小文字を区別しない。空欄は `xx`、末尾の空欄は省略できる
- 何も入力していない2人は `#` なし。3人は `#--`、4人は `#---`、ランダム相手は `#xx-??`
- 重複したカードは後ろを空欄にして読み込む。URLが無い・不正なときは端末の保存内容から復元する
- URLに入るのは、いま表示しているモードの入力だけ(ランダム相手のURLに、隠れている P2〜P4 は入らない)。端末の保存には隠れた分も含めて残る。リロードで同じURLを開くと隠れた分も戻るが、他の人のURLには持ち込まれない
- 入力のたびのURL更新は履歴を増やさない(「戻る」でカードが1手ずつ戻らない)
- 静的ホスティング(GitHub Pages など)で動くよう、パスではなく `#` 形式にしている

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面・スタイル・ヘルプ |
| `app.js` | カード入力UI / カード状態 / 結果表示 / 保存 |
| `state.js` | 入力状態の純関数(URLの書き出し・読み込み / 重複の整理 / 保存データの検証 / ランダム配布)。UI非依存 |
| `engine.js` | 役評価・Exact・Monte Carlo・最強の5枚。UI非依存、外部依存なし |
| `verify.js` | 検証コード。ヘルプの奥「開発者向け」を開いたときだけ読み込まれる |

## 検証

`?` → 一番下の「開発者向け: 計算の検証」を開く。

- **計算が正しいか確認**: 5枚役の全分布の照合 / 別方式の評価器との勝敗照合 / 既知ケース(正解値・Exact・Monte Carlo) / ランダム相手(別方式での数え直し、厳密値との照合) / 最終役の見込み(別方式の判定・Monte Carlo との照合) / 入力状態の整理(重複の整理・URLの往復・保存データ・ランダム配布)
- **計算速度を測る**: Exactの所要時間。スマートフォン実機で測ること

既知ケースの `expected` は、ルールから確定できる値か手計算の値のみ。`expected: null` は、外部の信頼できる計算機の値を入れる枠(サイト名・URL・取得日・条件・引き分けの扱いを併記すること)。推測値は入れない。

## 動かし方

静的ファイルのみ。`index.html` を開くか、GitHub Pages などにそのまま置く。ビルド不要。
