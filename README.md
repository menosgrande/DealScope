# DealScope

DealScope は、既知のホールカードとボードを入力すると、各プレイヤーの現在のカード勝率を表示する小型Webツール。
SPECTRAとは独立しており、レンジ・GTO・戦略解説などは扱いません。

## 使い方

1. 画面下の ▼ を押してカードピッカーを開く(閉じるときは ×)
2. カードを選ぶと、次の未入力枠へ自動で移動する
3. 全プレイヤーのホールカード2枚が揃うと、勝率が表示される
   - ボードは Flop(3枚) / Turn / River の順に入力
   - 計算するのは、ボード0枚(プリフロップ) / Flop3枚 / +Turn / +River のとき。Flopが1〜2枚の入力途中などは「入力待ち」

- 入力済みの枠をタップすると、そのカードを選び直せる(「外す」で空にもできる)
- 他の枠で使用中のカードはピッカーで選べない
- 人数は上部の `− ＋` で1〜4人に変更できる。減らしたプレイヤーのカードは破棄される
- **1人**にすると「Hero vs ランダムな相手1人」の勝率になる(相手のカードを入力しなくてよい)
- 入力中のカードと人数は端末に保存され、リロードしても復元される(保存データに同じカードが重複していた場合は、後ろのカードを空欄にして復元。形式が壊れている場合は復元しない)
- スートは4色固定(♠黒 ♥赤 ♦青 ♣緑)
- 上部の「リンクをコピー」で、今の局面のURLをコピーできる(下記)
- 「リセット」で全カードを消去

## URL

入力状態はURLの `#` 以降に反映される(開くだけで同じ局面を再現できる)。

```
index.html#AdTs-2c7h                    2人。P1 = A♦T♠、P2 = 2♣7♥
index.html#AdTs-2c7h/Kh7d3s             + Flop K♥7♦3♠
index.html#AdTs-2c7h/Kh7d3s/Qc/2h       + Turn Q♣ + River 2♥
index.html#AdTs-2c7h-KdKs               3人
index.html#AdTs/Kh7d3s                  1人(Hero vs ランダム) + Flop
```

- `P1[-P2[-P3[-P4]]]/Flop/Turn/River`。人数はハンドの数で決まる(1〜4)。1人で何も入力していないときは `#xx`
- カードは「ランク(`AKQJT98765432`)+スート(`shdc`)」の2文字。読み込み時は大文字小文字を区別しない
- 空欄は `xx`。末尾の空欄は省略できる
- 重複したカードは後ろを空欄にして読み込む。URLが無い・不正なときは端末の保存内容から復元する
- 入力のたびのURL更新は履歴を増やさない(「戻る」でカードが1手ずつ戻らない)
- 静的ホスティング(GitHub Pages など)で動くよう、パスではなく `#` 形式にしている

## ランダム相手(1人モード)

Heroの2枚とボードだけ入力し、相手1人は残りのカードからランダムと仮定した勝率。

| ストリート | 方式 | 表示 |
|---|---|---|
| Preflop | Monte Carlo(100,000回) | `≈66.9%`(実行のたびに少し変わる) |
| Flop / Turn / River | Exact(相手の全組み合わせ × 未公開ボードを全列挙) | `70.2%` |

`≈` が付くのは近似のときだけ。

## 勝率の定義

引き分けは取り分を等分して計算する(ポット分配を考慮したequity相当)。
例: 2人が引き分けたら、それぞれ0.5勝として数える。

## 計算方式

- **Exact(本番)**: 残りデックから成立する全ランアウトを列挙。同じ入力なら必ず同じ結果になる。約12msずつに分けて実行するため、計算中も画面は固まらない。
- **Monte Carlo(検証用)**: Exactの確認用。乱数・ランアウト生成・集計はExactとは別コードパス。
- 本番の表示は常にExact。Monte Carloには自動で切り替えない(端末によって数字が変わるのを避けるため)。
- 計算が重い端末で画面が重くなる場合は、別スレッド(Web Worker)化を検討する。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面とスタイル |
| `app.js` | カード入力UI / カード状態 / 結果表示 |
| `engine.js` | 役評価・Exact・Monte Carlo(UI非依存、外部依存なし) |
| `verify.js` | 検証コード。ページ下部の「検証」を開いたときだけ読み込まれる |

```
UI(Player 1〜4 / Board / カードピッカー)
        ↓
カード状態 (app.js)
        ↓
勝率エンジン (engine.js)
        ↓
結果表示
```

## 検証

ページ下部の「検証」ボタンでパネルを開く(同じページ内)。

- **正しさの検証**
  1. 5枚役の全分布(2,598,960通り)が公表されている件数と一致するか
  2. 高速評価器と、独立実装の素朴な評価器の勝敗が一致するか
  3. 既知ケースで、期待値・Exact・Monte Carlo(1万 / 5万 / 10万回)を比較
- **速度測定**: プリフロップ・フロップ・ターン・リバー、4人戦などのExact所要時間を表示。スマートフォン実機で測ること。

既知ケース(`verify.js` の `CASES`)の `expected` は、ルールから確定できる値か手計算の値のみ。
`expected: null` のケースは、外部の信頼できる計算機の値を入れるための枠。推測値は入れないこと。

Monte CarloはExactと完全一致する必要はなく、試行回数を増やすとExactへ収束することを確認する(判定は4σ以内)。

## 動かし方

静的ファイルのみ。`index.html` を開くか、GitHub Pages などにそのまま置く。ビルド不要。
